# Karten-Sprites

Der Asset-Ordner ist jetzt auf ein normales Blackjack-Kartenset vorbereitet.

Ordnerstruktur:

- `assets/cards/pik/`
- `assets/cards/herz/`
- `assets/cards/karo/`
- `assets/cards/kreuz/`

Dateinamen pro Farbe:

- `2.png`
- `3.png`
- `4.png`
- `5.png`
- `6.png`
- `7.png`
- `8.png`
- `9.png`
- `10.png`
- `j.png`
- `q.png`
- `k.png`
- `a.png`

Beispiele:

- `assets/cards/pik/a.png`
- `assets/cards/herz/10.png`
- `assets/cards/karo/q.png`
- `assets/cards/kreuz/2.png`

Empfehlung:

- Format pro Karte: `256x384` oder `320x480`
- PNG
- Pixelart mit klaren Kanten
- moeglichst gleicher Bildausschnitt fuer alle 52 Karten

Wenn eine Datei fehlt, zeigt das Spiel automatisch einen Platzhalter an.

Spaetere Spezialkarten koennen wir danach bequem in einem zusaetzlichen Unterordner wie `assets/cards/special/` ablegen.
